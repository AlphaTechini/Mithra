# Traceability

Every spec ID of `specs.md` with where it is implemented, which tests prove it, and its status. Written for M12; every file and test name below was checked by a script against the repository when this was written (a name that did not exist failed the check). Test names are the exact `it(...)` titles, Daml Script function names, or the `test.step` titles of the Playwright walk (a name that is a leading part of a longer title is a prefix of it).

## Status

| Status | Meaning |
|---|---|
| `met` | Implemented and proved by the tests listed; they ran in the build environment (Daml Script via the Docker image, Vitest, integration tests against the Canton sandbox and PostgreSQL, Playwright against the full-stack test server). |
| `met (owner to verify on LocalNet)` | Implemented and unit-tested, but the real thing needs the LocalNet or DecMan images, which cannot be pulled in the build environment. The owner's checklist is `docs/verification.md`. |
| `met (owner to verify on MainNet)` | Implemented and tested against fakes; it needs a real Grofty Wallet and real CC on Canton MainNet. Checklist: `docs/verification.md`, "MainNet payouts with Grofty". |
| `deviation (decision 11)` | Deliberately different from the spec; see `docs/decisions.md`. |
| `owner` | The product owner's to do: videos, publishing, submission. |

Test tiers: **Daml Script** (`scripts/daml.sh test`), **Vitest** (`pnpm test`), **Integration** (`cd apps/backend && npx vitest run --config vitest.integration.config.ts`, needs the Canton sandbox and PostgreSQL), **Playwright** (`pnpm e2e`, the whole happy path in a browser).
