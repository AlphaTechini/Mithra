## Goal
A clean pnpm monorepo where `pnpm install && pnpm lint && pnpm typecheck && pnpm test && pnpm build` all pass from a fresh clone. The Fastify backend starts, validates its environment and fails with a clear message naming every missing variable, serves `GET /api/health`, and in production also serves the built SvelteKit frontend from the same process. The SvelteKit app is frontend only (no server routes, no SSR) and talks to the backend through `/api`.

## Context
- Product: `details.md`; UI: `userflow.md` Section 1 (later milestones build the UI; here only the shell); requirements: `specs.md` Section 6 (tech stack) and the rows below.
- Architecture: Fastify is the whole backend (`apps/backend`); SvelteKit is frontend only (`apps/web`); shared types and Zod schemas in `packages/shared`; Daml in `daml/` (not yours).
- Networks: `localnet` and `mainnet` only, selected by `NETWORK`. All endpoints, party IDs and keys come from env.
- Money uses decimal arithmetic (`decimal.js`); amounts travel as strings. The LLM never computes amounts.
