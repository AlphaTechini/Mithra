## Files to create or change (all under `apps/web/src/`)
Styles and fonts:
- `lib/styles/tokens.css` — CSS custom properties. Palette exactly: Porcelain `#F4F6F8` (app background), Night ink `#151A2D` (primary text, dark surfaces), Lapis `#1F3A6E` (primary actions, links, selected), Saffron seal `#D99A1E` (**only** seal components may reference `--color-seal`), Verdigris `#2E7D6A` (paid, passed, active grants), Garnet `#A23A4E` (flags, failures, expired, denied). Derive surface, border, muted text and focus-ring tokens, and a dark theme from the same hues (`prefers-color-scheme: dark` plus `[data-theme='dark']`), checking WCAG AA (4.5:1 body text, 3:1 large text and UI) in both themes; document each pair's contrast ratio in a comment. Type scale 13/15/18/24/32/44 px, body 15 px, line length under 75ch, spacing scale, radii, shadows (subtle).
- `lib/styles/base.css` — reset, body font Public Sans, headings and large amounts Newsreader with `font-variant-numeric: tabular-nums lining-nums`, sentence case (no `text-transform: uppercase` anywhere), visible focus ring on every interactive element (`:focus-visible`), `prefers-reduced-motion: reduce` disables transitions and animations globally.
- Fonts: import `@fontsource/newsreader` (400, 500, 600) and `@fontsource/public-sans` (400, 500, 600) in the root layout so they are bundled and self-hosted (no Google Fonts requests).

Components (`lib/components/`), each with a short comment on purpose, accessible names, and keyboard behavior:
- `Button.svelte` — variants `primary` (Lapis), `secondary`, `quiet`, `danger` (Garnet outline); `busy` state shows a spinner and keeps width; `type` defaults to `button`.
- `Seal.svelte` — the signature ring. Props: `required: number` (segments), `signed: number` (from the ledger only; the component has no internal way to increment), `label: string` (e.g. "Approved 2 of 3"), `state: 'open' | 'sealed' | 'expiring'`, `expiresAt?`, `grantedAt?` (for `expiring`, the ring empties proportionally to time left), `size`. Saffron fill per signed segment with a short settle animation (≤ 400 ms) when `signed` increases; when `signed >= required` the ring becomes a solid seal stamped with `label`. SVG with `role="img"` and an `aria-label` that states the count in words ("2 of 3 signatures"). Reduced motion: state changes without animation. Saffron is used here and nowhere else.
- `AgentTimeline.svelte` — vertical timeline of steps `{ id, label, status: 'pending' | 'running' | 'done' | 'failed', detail?, at? }`; steps fill in as props change (the only motion that runs without a user action; respect reduced motion); `aria-live="polite"` announces each completed step.
- `AgentPanel.svelte` — right-side slide-in panel (on phones a full-screen sheet) with a chat transcript, a prompt box with suggested prompts as buttons, and tool-use `ActionCard`s inline. Props/events only; the data layer comes later. Opens from a button in the layout header and with the keyboard shortcut `Ctrl/Cmd+K`; focus is trapped while open, `Escape` closes, focus returns to the opener.
- `ActionCard.svelte` — compact, expandable card for one agent tool call (`title`, `status`, `summary`, expandable `details` slot or key/value list), e.g. "Created proposal for September, 4 payees, 1,200 CC".
- `StatusChip.svelte` — icon + word, never color alone. Kinds: `paid` ("Paid", Verdigris), `paid-auto` ("Paid automatically"), `awaiting-approval` ("Awaiting approval 1 of 2"), `awaiting-acceptance` ("Awaiting acceptance"), `pending` ("Pending ledger confirmation"), `rejected` ("Rejected", Garnet), `cancelled`, `flagged` ("Flagged"), `passed` ("Passed"), `active` ("Active until …"), `expired` ("Access ended …"), `denied` ("Request denied"), `seeded` ("Seeded", neutral, U8). Inline SVG icons (no icon font, no CDN).
- `Amount.svelte` — renders a decimal **string** with thousands separators and the asset symbol, trimming trailing zeros but keeping at least 2 decimals unless `exact` is set (show all 10); uses Newsreader for `size="large"`. Never converts to a JS number (format by string manipulation or `decimal.js`, add `decimal.js` to web deps if you use it). Unit test it.
- `DataTable.svelte` — accessible `<table>` with a caption, numeric columns right-aligned, and at ≤ 600 px each row becomes a stacked card with label/value pairs (CSS only, the same DOM, `data-label` attributes).
- `Skeleton.svelte` (shapes: line, block, table rows), `EmptyState.svelte` (one sentence plus one action), `ErrorState.svelte` (what failed + what to do + optional Retry; never a raw code alone), `PendingNotice.svelte` ("Waiting for the ledger to confirm…" with a spinner; used until confirmation).
- `NetworkBadge.svelte` — "LocalNet test mode" (persistent, visible on every screen in LocalNet, including landing and sign-in) or "MainNet".
- `RoleSwitcher.svelte` — LocalNet only: a labelled select/menu listing demo parties from `/api/session/demo-parties` grouped by role ("Treasurer", "Approver 1, 2, 3", "Holders A to D", "Auditor"), calls `POST /api/session/switch`, then re-routes by `primaryRole`.
