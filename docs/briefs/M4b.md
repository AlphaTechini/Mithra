## Goal
The treasurer can create the organization, issue units to holders, create invitation links, read the holders table, the overview, the activity log and the infrastructure panel; a holder can read their own position, accept units, turn on auto-receive and accept a pending payment; on LocalNet the treasurer can add funds to the treasury. A holder never receives another holder's data from any of these routes, including in errors.
